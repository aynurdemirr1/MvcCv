
💻 ASP.NET MVC5 ile Admin Panelli Dinamik CV Sitesi

Murat Yücedağ’ın eğitim serisini tamamlayarak geliştirdiğim, dinamik ve yönetilebilir bir CV sitesi projesi.

📌 Projenin Amacı:
Kullanıcıların kişisel bilgilerini şık ve düzenli bir yapıda sunabileceği, admin paneli ile kontrol edebileceği bir sistem oluşturmak.

🛠️ Kullanılan Teknolojiler:
C#, ASP.NET MVC, HTML, CSS, JavaScript, MSSQL, Entity Framework (DbFirst)

🎯 Projede Edindiğim Kazanımlar:
✅ Repository Design Pattern yapısını kullanma

✅ Authorize yapısı ile güvenli giriş işlemleri

✅ Formlara Required kontrolü ekleme

✅ PartialView kullanımı ile düzenli yapı oluşturma

✅ Entity Framework DbFirst yaklaşımında pratik kazanma

✅ MVC mimarisinde katmanlı yapı mantığını oturtma

🔐 Login Paneli:
Yetkilendirilmiş kullanıcılar giriş yaptıktan sonra admin paneline ulaşabiliyor ve içerik yönetimini gerçekleştirebiliyor.
